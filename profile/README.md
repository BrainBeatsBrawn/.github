# Brain Beats Brawn

The Brains Beats Brawn project is a UKRI Future Leader Fellowship hosted by Opteran Technologies (www.opteran.com).  The research aims to reverse engineer insect brains to create software that enables autonomous machines.

The resources made available in this repository represent the publicly avaialble outcomes of the research.

## Reconstructing Ant Visual Histories Project
This research project demonstrated a novel pipeline that fuses animal tracking, habitat mapping, insect eye modelling, and insect eye rendering tools to create an integrated dataset.
The datatset can be used to recreate the visual input that insect eyes will have passed to the animals brain as each animal explored and learned to navigate it's complex desert environment.
